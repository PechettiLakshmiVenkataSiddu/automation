# Aether

Aether is a personal AI automation platform for securely orchestrating AI-assisted work across communication, planning, knowledge, developer, browser, and desktop workflows.

This repository is being delivered in governed phases. Phases 0, 2–9 establish the product, architecture, repository, database, authentication, backend, frontend, dashboard, and AI-chat baselines.

## Current phase

Phase 9 — AI Chat
